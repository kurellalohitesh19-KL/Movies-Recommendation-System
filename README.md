🎬 Movie Recommendation System

A simple **content-based movie recommendation system** built using **Python, Machine Learning, and Streamlit**.

The application allows users to select a movie and recommends similar movies using **cosine similarity**.

🛠️Technologies

* Python
* Pandas
* Scikit-learn
* Streamlit
* Joblib

🚀 Run the Project

Install the required libraries:

'''bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```

📌 Features

* Select a movie
* Get similar movie recommendations
* Simple and interactive Streamlit interface
